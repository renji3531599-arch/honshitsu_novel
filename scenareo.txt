# 『まだ地図の途中で』〜✝本質✝特別編〜
### 桐葉高校理数科三年B組・卒業前ノベルゲームシナリオ企画書

## 0. この文書について

- 本書は、既存の小説「偏差値60の教室から✝本質✝が漏れ出している件について」(桐葉高校理数科三部作)の世界観・キャラクターを土台にした**完全オリジナルの番外編シナリオ**です。原作の地の文・台詞の引用や転載は行わず、全編書き下ろしの新規ストーリーとして構成しています。

## 1. ログライン

三年間、生徒たちは"✝本質✝"というわけのわからない合言葉を育ててきた。
三年間、地理教師・塀勝也はいつも同じ地図を見せ、いつも窓の外を五秒だけ見て、何かをつぶやいていた。
理由を聞いた生徒は、一人もいない。

卒業まで、あと一ヶ月。
地図の筒から、一枚の古い写真がこぼれ落ちたその日から――
「教わる側」だった生徒たちが、初めて「先生を知る」側に回る。

これは、桐葉高校理数科三年B組、誰も置き去りにしない、最後の学期の話。

---

## 2. コンセプトの核

**「見えないけど、ある」**――原作全体を貫くこのテーマを、そのまま塀勝也という一人の教師の内面に折り返す。

- 生徒たちは三年間、意味のないものに意味を見出す遊び(✝本質✝)を続けてきた。
- 実は勝也自身が、何十年も前から同じことを一人でやっていた。ただし彼のそれは、遊びではなく**祈り**だった。
- 生徒たちが悪ふざけの延長で始めた"先生を知ろう"プロジェクトが、気づけば彼の一番深いところに触れてしまう。
- クライマックスで明かされるのは「感動的な正解」ではなく、「ずっと同じことをしていた者同士が、初めてお互いに気づく」という並走の構図。
- エンディングを迎えても✝本質✝の正体は最後まで言語化されない。原作の哲学(「わかった瞬間、それは本質でなくなる」)を裏切らないことを最優先する。

## 3. 引き継ぐ設定(原作から踏襲する既成事実)

シナリオ全体で矛盾を出さないよう、以下は原作準拠の確定事項として厳守する。

- 桐葉高校には南棟(中高一貫コース／偏差値70／紺ネクタイ)と北棟(理数科／偏差値60／えんじネクタイ)という見えない国境がある。
- 理数科は一学年一クラス40人、三年間クラス替えなし。三年B組は一年時からの完全な顔ぶれのまま卒業を迎える。
- 地理教師・塀勝也(通称ヘイカツ)は同じ地形図を毎年見せ、授業中に窓の外を見て五秒黙り、何か呟く癖がある。誰も理由を聞かない。
- 両馬二郎が「✝本質✝」という言葉を広め、匿名掲示板・合格祈願掲示板・レビューサイトなどあらゆる場所に三重の名前を織り込んだ書き込みを続けている(裏アカウント「フェイカツ」も存在)。
- 三重県臣は冷笑系で「は？」が口癖。否定しながら誰よりも聞いている。三年目に入り、窓の外を見て「まあ」と言わない瞬間が増えている。
- 砂糖東洋はゲーマーで「窓の外は見ていない」と言い張るが、実際にはハワイの溶岩台地や通学電車の車窓を見ており、三年目最初の授業で初めて自分から地理の質問に手を挙げた。
- 数理零は全科目学年首席。評価の最高語彙は「面白い」。
- 寺地星は登録者数十〜千数百人規模のYouTubeチャンネル「星と地面とせいちちゃんねる」で「本質配信」を不定期開催。視聴者から届く意味不明な一言を紙に書いて読み上げ、その場で意味を見出そうとする。
- 召野カイトは二年時に既婚の副担任・二見玲子に恋をし、告白して「完了」した経験を持つ。以後、英語の成績が急上昇。
- 倉石暁は一学年下の理数科一年(→二年)生。両馬の熱心すぎる信奉者で、「✝本質✝年鑑」「✝本質✝入門ガイド」を自主編纂している。
- 内進二年(→三年)の櫻優は「恋愛学」の自称研究者で内藤蘭に片想い中。三峰瑠衣が世話役として伴走している。
- 一年目の合同課題で理数科と内進の混成チームが「時間の地形図――地面の歴史から読む防災マップ」で優勝し、海外研修(ハワイ)の予算を守った実績がある。
- 味噌・醤油・餅の形の東西分布、糸魚川−静岡構造線、河岸段丘、コーンスープの半年間の不在と帰還、翠湖マラソン、球技大会での二点差負け――これらは全て「本編で起きた既成事実」として会話の中で自然に参照してよい(再現・再演はしない。あくまで"思い出"として言及するのみ)。

## 4. 本特別編オリジナル要素

- **地図筒の中の古写真**：勝也の私物である古い地形図の収納筒から、彼の学生時代と思われる一枚の白黒/色褪せた写真がこぼれ落ちる。裏には万年筆で短い書き込みがある。
- **稲葉悌二(いなば・ていじ)**：写真に写るもう一人の人物。勝也がかつて所属していた地学系の部活動の指導者だった人物、という設定(本編には登場しない、本特別編オリジナルキャラクター。回想シーンのみ登場)。
- **勝也が「窓の外を見て五秒黙る」理由**：稲葉悌二への、誰にも告げない日々の報告。三年間同じ地図を見せ続ける授業スタイルも、稲葉から受け継いだやり方だった。
- **未回収の"ありがとう"**：勝也は稲葉に最後に会った日、素直になれず礼を言えなかった。彼は突然の事故でその機会を永遠に失っている。
- **両馬の祖父**：両馬が「✝本質✝」と言い始めた個人的な理由(祖父の口癖の模倣)。原作には存在しない、本特別編オリジナルの補完設定。勝也の"稲葉先生"と静かに対になる。
- **「思い出の地形図」**：生徒たちが持ち寄った写真・データ・エピソードを一枚の手作り地図に集約し、勝也へ贈る最終ギフト。三年間のモチーフ(翠湖、ハワイの溶岩台地、コーンスープ、糸魚川−静岡構造線、球技大会など)を"地形"として再配置したビジュアルの目玉CG。
- **掲示板の匿名住人「489」**：原作で二度ほど言及される、ヘイカツスレに書き込む謎の第三者。本特別編でも正体は明かさない。「わからないことこそが本質である」という原作の哲学を守るための意図的な未解決要素。

## 5.5 演出方針――「立ち絵芝居」と「専用CGシーン」の使い分け

本シナリオでは画像点数を無駄遣いせず、かつ「大胆に見せたい場面」でしっかり画力を投下するため、演出を二段階に分ける。

### Tier 1：通常会話(立ち絵＋背景の組み合わせ)
- 日常パート・コメディパートの大半はこの形式。背景1枚の上に、話者の立ち絵(表情差分)を1〜3体重ねる、一般的なノベルゲーム形式。
- 会話のテンポを優先し、専用CGは使わない。

### Tier 2：専用イベントCG(フル背景＋複数キャラの構図を描き起こす一枚絵)
- 感情のピークになる場面は、必ず「誰と誰が、どんな構図で、何を背景に」を明記した**専用一枚絵**を描き起こす。立ち絵の重ね合わせでは出せない、画角・距離感・視線の演出を狙う。
- 目安：シナリオ全体で40〜50枚程度を専用CGとして確保(後述アセット一覧の「名場面CG」参照)。
- 専用CGが入る場面の例と演出意図：
  - 二人だけの距離感を見せたい(例：三重と勝也、地図保管庫での見つめ合い) → ミディアムショット、二人の間の"空気"が伝わる構図。
  - 大人数の集合・団結を見せたい(例：教室に全員が集まって地図を作る) → 俯瞰または横一列の集合構図、手元(地図・写真・ペン)にもフォーカス。
  - 一人の孤独・内面を見せたい(例：勝也が誰もいない教室で窓を見る) → 後ろ姿中心のロングショット、逆光・夕焼けなどの光の演出。
  - 過去と現在の対比を見せたい(例：若き勝也と稲葉の回想 → 現在の勝也の横顔) → 色調を変えて(回想は褪色・セピア寄り)対比を強調。
- 命名規則：`cg_[連番]_[登場キャラ略称]_[場面概要].png` (例：`cg_07_mie-katsuya_chizutsutsu.png` は「三重×勝也、地図筒の場面」を示す)。

## 7. フラグ管理表

### 7.1 心Point(こころポイント)
- シナリオ全体を通して増減する隠しゲージ(-10〜+30を想定)。数値そのものはプレイヤーには非表示。
- 「相手の気持ちに寄り添う選択」「本音で向き合う選択」で加点。「茶化すだけで流す選択」「詮索を優先する選択」で減点or据え置き。
- クライマックスの深度(勝也がどこまで語るか)とEDのTier(TRUE／GOOD／NORMAL／BITTERSWEET)を決定する主要変数。

| 心Point合計 | 到達するEDのTier |
|---|---|
| 24以上 かつ 主要Flag8種中6種以上達成 | TRUE END |
| 18〜23 かつ 特定キャラFlagが突出 | 該当キャラのGOOD END |
| 12〜23(突出Flagなし) | NORMAL END |
| 11以下 | BITTERSWEET END |
| (特殊条件、7.3参照) | COMEDY SECRET END |
| 全ED回収後、TITLE画面に条件出現 | BONUS EXTRA |

### 7.2 キャラ別Flag一覧

| Flag名 | 主な加算シーン | 概要 |
|---|---|---|
| FLAG_MIE | 第一章、収束章 | 三重が写真を独り占めせず、誠実に向き合ったか |
| FLAG_SATOU | 砂糖編 | 「見てた」を素直に認めさせられたか |
| FLAG_REI | 零編 | 「詮索とお礼の違い」を零と共有できたか |
| FLAG_TERACHI | 寺地編 | 暴露ではなく"ありがとう"の会にすると合意できたか |
| FLAG_RYOMA | 両馬編 | 祖父のエピソードを両馬自身の言葉で話してもらえたか |
| FLAG_MINAMITOU | 南棟編 | 三峰・櫻・内藤を「他人事」にせず巻き込めたか |
| FLAG_MESHINO_KURAISHI | 召野+倉石編 | 二見先生からのヒントと、倉石の書庫調査、両方を丁寧に扱えたか |
| FLAG_IZAKI_IZUMI | 収束章 | 当日の進行・段取りを破綻なくまとめられたか |

- 主要Flag8種＝上記8つ。TRUE ENDには6種以上の達成が必要。
- 各ルートの選択肢には「心Pointのみ加点」「心Point＋該当Flag加点」の両方が混在し、プレイヤーの取捨選択に意味を持たせる。

### 7.3 COMEDY SECRET END 特殊条件
- FLAG_RYOMA と 倉石関連の"茶化し選択"を全て選んだ上で、心Pointが12〜17の中間帯に収まっている場合にのみ出現。
- 「大真面目にふざける」を貫いた者だけが辿り着く、原作らしい"照れ隠しのご褒美"ルート。

### 7.4 BONUS EXTRA 解放条件
- TRUE END＋GOOD END全8種＋NORMAL END＋BITTERSWEET END＋COMEDY SECRET ENDの、計12種類を一度でも回収済みであること。

## 10. 本編シナリオ

### 10.0 表記凡例

- `【BG:ID】` 背景指定／`【CG:ID】` 専用イベントCG(この間は背景差し替え)／`【BGM:ID】`／`【SE:ID】`
- `【立ち絵:キャラ略称/表情番号】` 立ち絵と表情の指定(複数体は「,」区切り)
- 話者名は太字。ナレーションは話者指定なしの地の文。
- 選択肢は `◆選択肢` ブロックで明示し、各選択肢の下に加算Flag・心Pointを注記する。
- 「※演出メモ」は制作者向けの補足であり、プレイヤーには表示されない。

## 13. 制作上の注意(トーンガイド)

本特別編の脚本・演出において、原作の空気を壊さないために以下を徹底する。

1. **説明過多にしない**。勝也の告白シーンでも、稲葉悌二について語られるのは"必要な分だけ"。生い立ちや細かい経歴を饒舌に語らせない。原作のキャラクターは総じて、大事なことほど短く言う。
2. **茶化しと本音の比率を崩さない**。感動シーンの直前直後に、必ず一言か二言、いつも通りのボケ・ツッコミを挟む。原作の全編がそうであるように、湿っぽさだけで押し切らない。
3. **489は明かさない**。「わからないことこそが本質」という原作の核を裏切らないため、TRUE ENDを含むいかなるルートでも489の正体には言及しない。
4. **勝也を"救われる存在"として消費しない**。生徒たちが彼を励ます、慰める、という構図に寄せすぎず、あくまで「初めて気づき合った」対等な関係性として描く。
5. **誰も置き去りにしない**。北棟だけでなく南棟の面々にも必ず出番と成長の着地点を用意する。原作が大切にしてきた「国境の内と外」という主題を、この特別編でも軽視しない。
6. **✝本質✝は最後まで定義しない**。クライマックスで勝也が語る「意味のないものに意味を見出す」という言葉も、あくまで"彼なりの言語化"であり、✝本質✝そのものの正解ではない。プレイヤーにも、いかなる攻略情報にも、✝本質✝の定義を断定させない。

## 16. まとめ

本書は、原作三部作が三年かけて積み上げてきた「何も解決しないが、確かに変わっていく」という空気を壊さないまま、卒業という一度きりの区切りに"意味のないはずの合言葉"を橋渡しさせる番外編として設計した。

タイトルの「まだ地図の途中で」は、二重の意味を持つ。ひとつは、勝也が三年間かけて生徒たちに見せ続けた地図そのもの。もうひとつは、生徒たちがこれから歩いていく、まだ誰も知らない地図。

卒業しても、✝本質✝は終わらない。地面は、忘れない。
――それだけで、十分だ。

**(企画書・シナリオ本文　完)**
