## 📖 物語概要（ネタバレなし）

> 三年間、地理教師・塀勝也は同じ地図を見せ、窓の外を五秒見て、何かを呟いていた。  
> 理由を聞いた生徒は、一人もいない。  
> 卒業まで、あと一ヶ月。地図の筒からこぼれた一枚の古写真をきっかけに、  
> 「教わる側」だった生徒たちが、初めて「先生を知る」側に回る ——。

- **原作準拠**：偏差値60（理数科・えんじ）vs 70（内進・紺）の国境、✝本質✝、コーンスープの不在、翠湖マラソン、球技大会二点差、ハワイ溶岩台地、フェイカツ、489 など全要素を会話の中で自然に参照。
- **特別編オリジナル**：古写真、稲葉悌二（回想のみ）、両馬の祖父、思い出の地形図、489の謎は**明かさない**。原作の哲学「わかった瞬間に本質でなくなる」を徹底。

## 🗺️ ゲーム構造

```
プロローグ → 第一章（写真発見） → HUB（6ルート自由選択） → 収束章「地図を作る夜」 → クライマックス「窓の外に、ずっといた人」 → 14種END分岐
```

### HUB 6ルート
|  | タイトル | 担当 | Flag |
|---|---|---|---|
| **A** | 窓の外の続き | 砂糖東洋 | FLAG_SATOU |
| **B** | 面白いの向こう側 | 数理零 | FLAG_REI |
| **C** | 最後の朗読、まだ早いけど | 寺地星 | FLAG_TERACHI |
| **D** | 祖父と✝本質✝ | 両馬二郎 | FLAG_RYOMA |
| **E** | 境界線の向こう側 | 南棟（三峰・櫻・内藤） | FLAG_MINAMITOU |
| **F** | 調査と応援 | 召野カイト + 倉石暁 | FLAG_MESHINO_KURAISHI |

全ルート読了で収束章へ。未読があると「まだ聞けていない話がある気がする」でHUBに戻される。

### エンディング（14種）
- **TRUE END**「地面は、忘れない。」：心Point 24+ かつ 主要Flag 8種中6種以上
- **GOOD END 8種**：各キャラFlag突出 + 心Point 18+（三重 / 砂糖 / 零 / 寺地 / 両馬 / 伊崎+伊豆見 / 召野 / 倉石 / 南棟）
- **NORMAL END**「見えないけど、ある」：12〜23（突出なし）
- **BITTERSWEET END**「こぼれた地図」：11以下
- **COMEDY SECRET END**「原✝本質✝、完全体」：FLAG_RYOMA突出 + 心Point 12〜17（茶化し貫徹）
- **BONUS EXTRA**「また、この教室で」：全13END回収後、TITLEに隠し出現（翠湖同窓会）

クライマックスの深さ（勝也が涙を見せるか）は心Pointで演出が分岐。

## 🎨 演出へのこだわり（“超本格的”の正体）

- **フォント**：本文は `Shippori Mincho / Noto Serif JP`、UIは `Zen Kaku Gothic New`。原作の“地の文”の質感を縦書き的レイアウトで再現。
- **レイアウト**：16:9 レターボックス、背景は24枚のグラデーションプレースホルダ（`assets/bg/bg_*.png`）にフィルムグレイン＋ヴィネット。`assets/cg/cg_*.png` は額縁演出で表示。
- **立ち絵芝居**：113差分を `chr_*/chr_*.png` にリネーム。話者は `focus+talking`、非話者は `dim` で自動フォーカス。表情差分はプレートに表示。
- **BGM/SE**：企画書のキュー24曲・SE15種を右上「♪」インジケータで可視化。仮素材ではテキスト＋軽いWebAudio効果音で代替。
- **タイプウェル**：文字送りタイプライター、既読スキップ、オート、バックログ、セーブ/ロード（localStorage 6スロット）、コンフィグ、ギャラリー、TIPS辞典を完備。
- **桜演出**：タイトルはCanvasで舞う桜（28枚）を描画。卒業式・翠湖の季節感を象徴。
- **仮素材の扱い**：指示通り「中身は白ダミーのままでOK」。ただしファイル名は `209枚計画` 通りに300枚をリネーム済み。画面上は「仮素材」透かしとBGラベル、CGバッジ、キャラプレートで“製品版では描き下ろしに差し替え”が伝わる設計。

│   ├── chara/(105枚)   # chr_katsuya_01_tsujou.png など

### アセット命名規則（企画書 8章準拠）
- **BG**：`bg_*.png` 24枚
- **立ち絵**：`chr_[略称]_[番号]_[表情].png` 113枚（例 `chr_katsuya_01_tsujou.png`）
- **CG**：`cg_[連番]_[キャラ略]_[場面].png`（例 `cg_02.png` は地図筒から写真がこぼれる瞬間）
- **UI**：`ui01.png`〜`ui20.png`

## 🧪 技術メモ

- **依存ゼロ**：ビルド不要、Vanilla JS + CSSのみ。`python -m http.server` で即起動。
- **状態管理**：`localStorage` に `honshitsu_save_v1` キーで Heart/Flags/visited/cleared/CG/ENDINGS/seenText を永続化。
- **フラグ管理**：企画書7章の `心Point (-10〜+30)` と `FLAG_* 8種` を完全再現。COMEDYは心Point 12〜17かつFLAG_RYOMA突出で判定（倉石茶化しの代理）。
- **プレビュー対応**：`0.0.0.0` バインド、iframe許可、Hostヘッダ許容。
