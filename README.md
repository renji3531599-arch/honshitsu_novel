# 『まだ地図の途中で　〜✝本質✝特別編〜』ノベルゲーム

`scenareo.txt`（企画書＆本編シナリオ）と `「偏差値60の教室から✝本質✝が漏れ出している件について」.txt`（原作小説）を精読して実装した、**実際に遊べる本格ノベルゲーム**です。

- **ジャンル**: 群像劇テキストアドベンチャー（ADV）
- **原典**: シナリオ企画書 §1〜§16 を全て実装（プロローグ → 第一章 → HUB6ルート → 収束章 → クライマックス → ED14種）
- **プレイ時間目安**: 1周約60〜90分／フルコンプ（END14種）で企画書想定どおりのボリューム

---

## 起動方法

リポジトリ直下で静的サーバーを立てて `game/` を開くだけです（ビルド不要・依存ライブラリなし）。

```bash
cd honshitsu_novel
python3 -m http.server 8000
# ブラウザで http://localhost:8000/game/ を開く
```

または `game/index.html` をローカルサーバー経由で任意のホスティングに置けます（file:// でも大半の機能は動作しますが、localStorage の保存は http 推奨）。

## 実装内容（エンジン仕様）

| 機能 | 内容 |
|---|---|
| 本編フロー | プロローグ／第一章（選択肢3択）／**HUB自由順6ルート**（A砂糖・B零・C寺地・D両馬・E南棟・F召野＋倉石）／収束章／クライマックス／**ED14種** |
| 心Point＆Flag | 企画書§7どおりの隠しパラメータ（心Point / 主要Flag8種 / 倉石茶化しカウンタ / 召野・倉石サイド判定）。設定画面で内部表示ONにできます |
| エンディング判定 | TRUE（心24以上＋Flag6種以上）／GOOD9種（18以上＋突出Flag）／NORMAL／BITTERSWEET（11以下）／COMEDY SECRET（両馬Flag最大＋倉石茶化し全選択＋心12〜17）／BONUS EXTRA（13種回収後にタイトルへ出現） |
| システム | セーブ12スロット＋クイック＋オートセーブ／ロードは黒字リプレイ方式でどこからでも復元／バックログ／既読スキップ（Ctrl押下可）／オートモード／ギャラリー（CG52種）／**✝本質✝辞典**（用語自動収集）／ENDリスト／設定（文字速・オート待ち・音量） |
| 演出 | 章タイトルカード／CG表示（企画書§8.3の38枚＋ED14枚）／**「窓の外、五秒」演出**（クライマックスでは15秒に延伸）／掲示板・配信UI（ui03/ui04/ui05）／回想は色調を褪色させた専用トーン |
| 画像 | `image1/2/3` の仮画像 `white_001〜300.png` を企画書§8のアセット一覧に従って**リネームして使用**（対応表: `ASSET_MAP.md`）。白紙のままでも「未完の地図」風の等高線背景・時間帯ティント・キャラ別カラーパネルで舞台として機能します。**同名の実素材を `game/assets/img/` に置き換えればそのまま反映**されます |
| 音楽・効果音 | 音源ファイル不使用。**WebAudioによるリアルタイム合成**で企画書§9のBGM24曲＋SE16種を内蔵（キー・テンポ・音色を切り替える手続き生成楽曲） |

## 実装メモ（企画書との差分）

- 企画書§14のFlag早見表の精神を維持しつつ、**選択肢の心Point増減をゲームバランス用に微調整**しています（主流の「②」系選択は+1→0、茶化しは-1など。TRUE END が自明にならないよう調整）。
- 企画書が推奨する「軽い相槌選択肢」（§14注記）を各ルートに1〜2個実装。**倉石関連の茶化し選択肢は3箇所**（F編×2＋収束章×1）あり、全て選ぶと COMEDY SECRET END の条件に乗ります。
- GOOD END の「召野側／倉石側」は、F編最後の選択肢（どちらが計画の入口だったか）で判定します。
- 収束章の伊崎・伊豆見Flagボーナス（§14「全ルートを丁寧に読了」）は、到達時点の心Point20以上を条件に実装。
- 「489」の正体は企画書§13のトーンガイドどおり**最後まで明かしません**（TRUE END の掲示板演出のみ）。

## 開発者向け

```bash
node tools/check_script.js        # シナリオデータの静的検証（0エラー必須）
node tools/playthrough_test.js    # 実プレイテスト3ルート（要: jsdom。npm i jsdom）
node tools/save_test.js           # セーブ/ロード/BONUSテスト（要: jsdom）
python3 tools/map_assets.py       # アセット割り当ての再生成（冪等）
```

実素材を差し替える場合: `ASSET_MAP.md` の対応表を見ながら `game/assets/img/` に**同名のファイル**を上書きするだけです。差分追加（企画書§8.6のバッファ）は `spare_202.png`〜`spare_300.png` をリネームして `assets_manifest.js` に追記してください。
