# まだ地図の途中で　〜✝本質✝特別編〜

「偏差値60の教室から✝本質✝が漏れ出している件について」の世界観で描く、
**完全プレイアブルなノベルゲーム**（Webブラウザ動作・オフライン完結）です。

`scenareo.txt`（企画書『まだ地図の途中で』）を精読し、その仕様——
プロローグ／第一章／HUB式6ルート／収束章／クライマックス／**エンディング14種**、
心Point＆8種のキャラ別フラグ、アセット命名規則、トーンガイド——を
そのまま実装したものです。原作小説の地の文・台詞は引用せず、
企画書の「書き下ろしシナリオ」として全編新規に実装しています。

---

## 起動方法

```bash
# リポジトリ直下で（任意の静的サーバーで可）
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

ビルド不要・外部依存なし（音声も全部ブラウザ内合成です）。

| 操作 | 内容 |
|---|---|
| クリック / Space / Enter / Z | テキスト送り（タイプ中表示中は一括表示） |
| Ctrl（押している間） | 既読スキップ |
| A | オートモード |
| L | バックログ |
| Esc | メニュー |

- **HUB「見送りの準備、始めます」**：6ルート（砂糖／零／寺地／両馬／南棟／召野＋倉石）を好きな順番で。全部読むと収束章へ。
- **心Point**（隠しパラメータ）と**キャラ別Flag 8種**で、エンディング14種が分岐します。
  - TRUE END：心Point 24以上 ＋ Flag8種中6種達成
  - GOOD END ×9：心Point 18〜23 ＋ Flag突出（三重／砂糖／零／寺地／両馬／伊崎＋伊豆見／召野／倉石／南棟）
  - NORMAL END：心Point 12〜23（突出なし）
  - BITTERSWEET END：心Point 11以下
  - COMEDY SECRET END：両馬Flag最大＋倉石関連の茶化し選択を全選択＋心Point12〜17
  - BONUS EXTRA「また、この教室で」：全13種回収後にタイトルへ
- 収集要素：**CGギャラリー**（52枚）、**✝本質✝辞典**（本編中で固有名詞を自動収集）、エンディングリスト。

> ※企画書7.4では「GOOD END全8種・計12種」とありますが、第11章の本文にはGOOD ENDが9種
> （伊崎＋伊豆見編と南棟編の双方）列挙されているため、本実装は**本文準拠の9種**を採用し、
> BONUS解放条件を「全13種回収」としています。

## 仮画像について（本番画像への差し替え）

現在の `assets/` は、UPされていた仮画像 `white_XXX.png` 300枚を
**企画書 第8章の正式ファイル名にリネーム**して配置したものです
（BG24／立ち絵105／CG38／ED-CG14／UI20、余り99枚は `assets/spare/`）。

- エンジンは各画像が**白紙（無地）かどうかを自動判定**し、
  白紙の間は「舞台札スタイル」（キャラ色の札・表情印・場所札・水面グラデ）で
  舞台芸術的に演出します（設定からON/OFF可）。
- **同名の本番PNGを `assets/` に上書き配置するだけで自動的に実画像表示に切り替わります。**
  コードの変更は不要です。命名規則は企画書準拠：
  - 背景 `assets/bg/bg_hokutou_kyoshitsu_asa.png`（BG01〜BG24）
  - 立ち絵 `assets/chr/chr_mie_02.png`（キャラ略称＋表情番号）
  - 専用CG `assets/cg/cg_02_mie-katsuya_shashin_koboreru.png`（cg01〜38）
  - ED-CG `assets/cg_end/cg_end_true.png`（14種）
  - UI `assets/ui/ui_01_title_logo.png`（20種）
