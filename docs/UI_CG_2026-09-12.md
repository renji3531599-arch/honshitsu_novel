# 2026-09-12 の整理 ―― UI画像の撤去とCGの「名場面のみ」化

ユーザー指摘を2件受けたので、**版A（ルート直下）・版B（`game/`）の両方**に同じ基準を適用した。

> 1. **UIのPNG、ほぼ全部いらない** ―― 企画書§8.5のUI画像20枚（ui01〜ui20）は、
>    エンジンがすでにCSS/SVGで全描画している（白紙プレースホルダは誰も参照していない）。
> 2. **CGは特に印象的で感動的なシーンのみで使うはず** ―― 企画書§5.5は
>    「通常会話では専用CGを使わない／専用CGは感情のピークに置く」と書いているのに、
>    実装は§8.3の38枚計画に従って非ピーク（呼び止め・手元アップ・廊下で喋るだけ等）にも
>    CGを立てていた。

---

## 1. UI画像20枚（ui01〜ui20）を撤去

| 版 | 対応 |
|---|---|
| 版A | `assets/ui/` のPNG20枚を削除。`data/assets.json` からuiカテゴリを除去（台帳 202→182行）。`tools/rename_assets.py`・`docs/ASSET_MANIFEST.md`・`tools/gen_asset_md.mjs` も追従 |
| 版B | `game/assets/img/ui*.png` 20枚を削除。`assets_manifest.js` からuiカテゴリ除去。`tools/map_assets.py` は「撤去済みスロット」を覚えて**冪等実行可能**なまま |

エンジン側でPNGを参照していたのは2箇所だけで、どちらもCSSに移設した：

- **版B 端末オーバーレイ**（`showNet`）: 旧 `ui03`/`ui05` フレームPNGの上に
  **96〜98%不透明のグラデーション**を重ねていた（＝PNGは実質ほぼ見えていなかった）。
  → グラデーションだけを `style.css` の `.net-panel` に移設。
- **版B タイトルロゴのプレート**（`index.html` のインラインスクリプト）: 旧 `ui01` を
  `opacity .14` で重ねていた（白紙なので「淡い明るい板」にしか見えていなかった）。
  → CSSの `radial-gradient` で同じ見え方を再現。

版Aは元からPNGへの参照ゼロ（`renderItems` のアイコン参照は台帳から解決できなければ
✝グリフにフォールバックする作りだったので、何も壊れていない）。

**画面上のUI（ツールバー・クイックメニュー・パネル類）はこのとおり残している。**
削ったのは「実ファイルとしてのUI画像」だけ。

## 2. おまけ系パネルをタイトルに集約（版Aのみ）

版Aはプレイ中からギャラリー／✝本質✝辞典／✝本質✝年鑑／ENDリストを開けた
（クイックメニュー9項目・キー G/T/R/Y・ENDカードの「回収した地図を見る」ボタン）。
企画書§12はこれらを「おまけコンテンツ」として位置づけているので、**タイトル画面からのみ**に集約：

- クイックメニューは「ログ／セーブ／ロード／設定／タイトルへ」に縮小
- プレイ中の G/T/R/Y キーを廃止（タイトル上では有効のまま）
- ENDカードからギャラリーへの導線を削除
- 版Bはもともとタイトルからしか開けない構成なので無変更

## 3. CGを「印象的で感動的なシーンのみ」に絞る

### 基準

> **CGを立たせるのは、引き金／各ルートの決定の瞬間／収束の夜／クライマックス／各ENDだけ。**
> 呼び止められただけ・手元アップ・並んで喋るだけ・状況説明の集合図 → 立ち絵＋背景で十分。

2026-09-11 の整理（`docs/PERF_2026-09-11.md` §4「場面転換と決定の瞬間だけ」）から
さらに一段絞り、**両版で同じ面子**に揃えた。

### 降板した9枚（今回分。両版共通の追加降板）

| CG | 場面 | 降板理由 |
|---|---|---|
| cg01 | プロローグ、三重が呼び止められる | 物語が動き出す前の通常会話 |
| cg03 | 写真の表と裏・手元アップ | 小物アップ。cg02（こぼれる瞬間）を見せていれば十分 |
| cg05 | 夕方の廊下で両馬に打ち明ける | 並んで喋るだけ（版Bでは3箇所で再掲していた） |
| cg06 | 車窓写真をスマホでスクロール | 手元アップ。背景（電車の車窓）＋モノローグで代替 |
| cg10 | 机の引き出しから三年分の紙束 | 小物アップ。「積み重ねた時間」は台詞が語っている |
| cg14 | 倉石が古い学校新聞を読む | 発見シーン（説明）。倉石の真剣な立ち絵で代替 |
| cg16 | 職員室で二見が微笑む | 静かな会話の一段。意味は台詞が担う |
| cg17 | 桜並木で三峰を待つ | 状況説明。背景（桜並木）そのもので成立 |
| cg18 | 南棟教室の集合図 | 状況説明。立ち絵3人＋背景で同じ情報が出る |

版Bはこれに加え、版Aが既に降板済みだった **cg11／cg15／cg21／cg24／cg25／cg32／cg37**
（頷き合う・報告・書き足す手元・絶句・「聞いていいですか」・朗読の立ち上がり・満開の桜ハモり）
と **cg05の3回再掲** も落とした。

### 結果（両版とも同じ）

- **本編のCG指定： 名場面18枚 ＋ ED専用14枚 ＝ 32枚**（版Aは41→32、版Bは49→32）
- CGが立つのは：
  - cg02（写真がこぼれる瞬間＝引き金）
  - cg07（砂糖「見てた」）／cg09（零「大事だと思うから」）／cg12・cg13（両馬の祖父）／cg19（内藤の決意）
  - cg20（全員で地図を作る夜）／cg22（「思い出の地形図」完成図）
  - cg23〜cg34（クライマックス9枚）／cg35（卒業式）
  - ED専用14枚（各END1枚）
- 降板20枚（上記9枚＋2026-09-11の11枚）は**ファイルは削除せず** `reserve` 扱い
  （版A: `data/assets.json` の `"reserve": true`、版B: マニフェストの `reserve` フラグ）。
  ギャラリー・回収分母には出ない。脚本に1行足せばいつでも再昇格できる。
- 寺地ルート・召野＋倉石ルートは一枚絵ゼロになったが、それが基準（＝ピーク以外に
  CGを立てない）の正しい帰結。

## 4. ついでに直した既存破損

- `package.json` の `"type": "module"` 追加以降、版Bの検証ツール
  （`tools/check_script.js` 等・CommonJS）が起動すらしなくなっていた →
  **`.cjs` にリネーム**して `node tools/check_script.cjs` で動くようにした。
  jsdom の require も `npm i --no-save jsdom` で入る `./node_modules` を見るように修正。

# 第2弾（同日）―― 白紙プレースホルダ実ファイルの一括削除

背景は両版とも実画像が揃った（版A 25枚／版B 24枚）ので、
残っていた**白紙プレースホルダ（810B の単色PNG）計512枚を全削除**した。
「いったん消す」方針：**名前・スロット・用途は台帳に全記録**してあるので、
実素材が届いたら台帳の `file` 名で新規配置すれば即差し替わる（復元も `white_NNN.png` を
白塗りPNGとして再生成すれば `tools/rename_assets.py`／`tools/map_assets.py` で可能）。

## 削除内訳

| 版 | 対象 | 枚数 | 削除後の実ファイル |
|---|---|---|---|
| 版A | `assets/cg/*.png`（白紙52枚） | 52 | なし |
| 版A | `assets/chr/*.png`（白紙105枚） | 105 | なし |
| 版A | `assets/_buffer/`（予備99枚・ディレクトリごと） | 99 | なし |
| 版B | `game/assets/img/` の `cg_*`38＋`cg_end_*`14＋`chr_*`105＋`spare_*`99 | 256 | 背景24枚のみ |
| 計 | | **512** | 背景：版A 25枚／版B 24枚 |

`assets/bg/`（版A）と `game/assets/img/bg_*`（版B）の**実画像は1枚も触っていない**。

## 同時に整えたもの

- **版A台帳 `data/assets.json`**: 182→162行（bg25/chr105/cg32）。reserve CG 行と `bufferFiles` を削除。
- **版A `tools/gen_asset_md.mjs`**: `_buffer` 出力・バッファ説明を撤去。未配置は「スロット登録のみ（実ファイルは未配置）」と表示。
  差し替え手順は「台帳の `file` 名で新規配置」に変更。CG_GUIDE は32枚物語順で再生成。
- **版A `docs/ASSET_MANIFEST.md`**: 内訳を削除後の実態に更新（バッファ節は削除記録に差し替え）。
- **版B `tools/map_assets.py`**: 全 `take()` を `keep_missing` 対応に。降板CG・予備は「実ファイル削除＋台帳記録のみ」、
  マニフェストから `spare` を廃止。`ASSET_MAP.md`・`game/js/assets_manifest.js` を再生成（冪等確認済み）。
- **版B `tools/check_script.cjs`**: `MAN.spare` 参照を削除（廃止後は落ちるため）。
- **版B `game/js/main.js`**: プリロード完了文言が「準備完了（背景 N/M を先読み。CG・立ち絵は未配置）」になり、
  読み漏れファイル数を握りつぶさず合計表示。`engine.js` のCG表示は白背景フォールバック付き。
- **版A `sw.js`**: CACHE `v4`→`v5`（旧キャッシュの白紙PNG配信防止）。
- **README.md**: 冒頭の共通事項・版A §3「画像について」・版Bツリー等を削除後の実態に全面更新
  （末尾に残っていた以前の壊れた追記ゴミも除去）。
